# Project Hand‑off Documentation

## Overview
This repository contains the **Good Drivers Defender** Android application, featuring:
- **AdMob** banner and interstitial ads integration.
- **Google Play Billing** (premium subscription to remove ads).
- Modern UI built with **Jetpack Compose**, **Material 3**, glass‑morphism styling, and smooth micro‑animations.
- Camera, location, and data‑storage capabilities.

## Prerequisites
1. **Java 17 JDK** – already bundled in `jdk17/jdk-17.0.19+10` (set `org.gradle.java.home` in `gradle.properties`).
2. **Android SDK** – API level 36 (compileSdk) and targetSdk 35+. Ensure `ANDROID_HOME` points to the SDK.
3. **Gradle Wrapper** – use the bundled `gradlew.*` scripts.
4. **Google Play services** – the project depends on `play-services-location` and `play-services-ads` (see `gradle/libs.versions.toml`).
5. **Firebase BoM** – required for analytics/crash reporting (optional for local builds).

## Build & Run Locally
```bash

# Run unit tests

# Install on a connected device/emulator
```
